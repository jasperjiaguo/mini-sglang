## Output inspection

The first smoke run exposed duplicated words and subwords in streamed speculative output. Verification can emit multiple tokens for one request in a single scheduler reply, while the detokenizer previously decoded every same-request message against stale offsets. Processing those messages sequentially fixes the issue.

After the fix, all 10,000 matrix completions and the 1,000 overlap completions had:

- zero Unicode replacement characters;
- zero adjacent repeated-word artifacts;
- exactly three bullet lines;
- no request reaching the 256-token cap.

Manually inspected baseline/speculative mismatches were coherent and grounded in the corresponding article/highlights. Greedy output is not numerically identical, however: exact string match against pure decoding ranges from 61.4% to 66.3% across the speculative matrix; `N=1, K=3` matches 614/1,000 with overlap off and 626/1,000 with overlap on. This is consistent with the branch's documented verification-forward numerical drift and remains a correctness concern even though the sampled text is semantically reasonable.

## PyTorch profile

Both comparison traces use 128 measured requests, 64 warmup requests, `N=1`, `K=3`, CUDA graph bucket 32, and 80 active profiler scheduler steps. Overlap off uses 32 running requests; overlap on uses 64 so two disjoint request groups can ping-pong through the fixed graph bucket.

| Metric | Overlap off | Overlap on |
| --- | ---: | ---: |
| Profiled QPS | 14.208 | 16.723 |
| GPU busy fraction | 51.40% | 70.95% |
| Inter-GPU-work gap p99 | 212.19 µs | 74.62 µs |
| Gaps > 50 µs | 1,975 | 456 |
| Gaps > 100 µs | 1,624 | 302 |
| Mean CUDA graph launch CPU duration | 726.79 µs | 687.03 µs |

The overlap-off trace shows the expected CPU launch/scheduler bubble between CUDA graph replays. Disjoint-group overlap reduces gaps over 50 µs by 76.9%, gaps over 100 µs by 81.4%, and raises GPU busy time by 19.55 percentage points. Each trace contains one large wave-boundary/profiler outlier (350–396 ms); the p99 and threshold counts better represent the recurring bubble.
